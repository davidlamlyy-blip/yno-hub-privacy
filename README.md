# yno Hub – Privacy Policy

yno Hub is a personal dashboard app that runs only on its owner's own computer. This page is its home page and privacy policy.

## What the app does
With the owner's permission, it reads and adds events on the owner's own Google Calendar and shows them in a calendar view.

## Data
- Calendar data is requested directly from Google to the owner's computer and displayed locally.
- The OAuth refresh token is stored only on the owner's computer.
- No data is uploaded to any server, shared with third parties, sold, or used for advertising.
- The app does not delete calendar events or share calendars.

## Google API Services
Use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access
Access can be removed at any time at https://myaccount.google.com/permissions.
